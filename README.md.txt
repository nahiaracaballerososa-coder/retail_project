Retail Project Pre- entrega 2

Proyecto de base de datos retail realizado con PostgreSQL.

El proyecto incluye:
- Tabla clientes.
- Tabla productos.
- Tabla ventas.
- Claves primarias en todas las tablas.
- Email único y no nulo para los clientes.
- Claves foráneas desde ventas hacia clientes y productos.
- Restricciones CHECK para validar edad, precio, stock, cantidad y precio unitario.
- Carga inicial de datos mediante una transacción BEGIN / COMMIT.
- Al menos 5 registros iniciales en cada tabla.
- Actualización de precios utilizando UPDATE y WHERE.
- Eliminación de una venta específica utilizando DELETE y WHERE.
